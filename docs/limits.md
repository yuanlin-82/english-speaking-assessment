# Limits and non-claims

1. **Not a vendor replacement** — accuracy / integrity internals stay with the speech provider unless separately rebuilt and validated.
2. **Not a CEFR/IELTS instrument** — optional band-style packaging is not the core claim of this methodology.
3. **Not dialogue orchestration** — multi-turn interview routing is out of scope here.
4. **Not production config** — weights, prompts, audio, and lexicons stay private ([NOTICE.md](../NOTICE.md)).
5. **Fluency is hard on short speech** — composition and UI should expose uncertainty, not fake precision.
6. **Expert alignment is ongoing** — “self-built fluency” implies a validation burden; publishing the chain is not the same as publishing a frozen model.
