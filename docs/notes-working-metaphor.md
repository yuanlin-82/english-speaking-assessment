# Working metaphor (optional intuition)

**Status:** author working note — useful for explaining probe geometry in conversation; **not** a measurement claim, not a philosophy-of-mind thesis, and **not** required to use the methodology in [task-vs-interaction.md](task-vs-interaction.md).

Hard to prove and hard to falsify. Treat as analogy.

---

## Sketch

One useful picture (related to lossy-compression / bottleneck metaphors elsewhere, not original here as a formal theory):

- What candidates *mean* to convey is richer than what a single utterance can carry.
- Observed speech is a thinner sample of that richness.
- Follow-ups are how the product gathers more of what the decision needs.

This repo’s public contracts do **not** depend on that picture. Operational language stays: job-evidence cells, cognitive–linguistic **demand**, channel vs object.

---

## Two probe geometries (metaphor → method)

| Metaphor (optional) | Operational counterpart (use this in products) |
| --- | --- |
| Competency probing as searching for a better **projection angle** on the same episode | **Multi-angle sampling**: choose the **high-gain aspect** that closes empty job-evidence cells |
| Interactive oral probing as **approaching** a level on a band | **Demand calibration**: place the next ask near the running oral-level estimate (stretch / scaffold / hold) |

Same LLM family can generate both kinds of next ask. The contracts differ: see [Same LLM follow-ups, different evidence gaps](task-vs-interaction.md#same-llm-follow-ups-different-evidence-gaps).

Language as **channel / means** (competency) vs **object / end** (oral ability) remains the non-philosophical product distinction in the main doc.
